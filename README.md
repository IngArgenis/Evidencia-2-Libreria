# Sistema de Biblioteca en Java

Repositorio de la evidencia 2 práctica. Este programa simula el registro y visualización de libros en una biblioteca utilizando arreglos estáticos básicos.

## 🛠️ ¿Qué hace este código?
El proyecto está estructurado en dos clases independientes (`Libro` y `Biblioteca`) y cumple con los siguientes requerimientos lógicos:
- **Creación de objetos:** Uso de un constructor para registrar libros con sus atributos principales (título, autor y año de publicación).
- **Almacenamiento manual:** Gestión de la colección utilizando un arreglo tradicional (`Array`) y una variable contador para controlar el límite de espacios disponibles.
- **Visualización de datos:** Un método que recorre únicamente los espacios ocupados del arreglo e imprime la información ordenada en la consola.
